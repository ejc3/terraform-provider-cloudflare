# cloudflare_workers_build_trigger (Resource)

Accepted Permissions

- `Workers CI Write`


Manages a typed Cloudflare Workers Builds production or preview trigger.

## Example Usage

```terraform
resource "cloudflare_workers_build_trigger" "preview" {
  account_id                 = "023e105f4ecef8ad9ca31a8372d0c353"
  external_script_id         = "72edf31f83e240448fce38bef56104e3"
  repository_connection_uuid = "11111111-1111-4111-8111-111111111111"
  build_token_uuid           = "22222222-2222-4222-8222-222222222222"
  trigger_name               = "Preview branches"
  build_command              = "npm run cf:build"
  deploy_command             = "npm run cf:upload:built"
  root_directory             = "/"
  branch_includes            = ["*"]
  branch_excludes            = ["main"]
  path_includes              = ["*"]
  path_excludes              = []
  build_caching_enabled      = true
}
```

## Schema

### Required

- `account_id` (String) Cloudflare account identifier.
- `branch_excludes` (Set of String) Branch patterns excluded from builds.
- `branch_includes` (Set of String) Branch patterns which trigger a build.
- `build_caching_enabled` (Boolean) Whether Workers Builds may reuse its build cache.
- `build_command` (String) Command used to build the Worker.
- `build_token_uuid` (String) Workers Builds deployment token UUID.
- `deploy_command` (String) Command used to deploy or upload the built Worker.
- `external_script_id` (String) Immutable Worker tag, not the Worker name.
- `path_excludes` (Set of String) Path patterns excluded from builds.
- `path_includes` (Set of String) Path patterns which trigger a build.
- `repository_connection_uuid` (String) Workers Builds repository connection UUID.
- `root_directory` (String) Repository directory in which commands run.
- `trigger_name` (String) Display name for the trigger.

- `created_on` (String) Creation timestamp reported by Cloudflare.
- `id` (String) Trigger UUID.
- `modified_on` (String) Last modification timestamp reported by Cloudflare.
